# point-study-skill

让具备文件读写能力的 AI 基于你的教材和笔记逐步授课，并用知识节点、简短检查与持久进度支持跨对话续学。

版本：`0.1.1` · 许可证：[MIT](LICENSE)

## 它可以做什么

把你已有的教材或笔记交给 AI，让它围绕本次学习范围当老师：

- 以教材确定范围、术语和符号，分清教材内容与补充解释；发现错误、矛盾或缺失时指出依据。
- 默认你没有预习。需要阅读时，先解释目的，再给出具体文件和阅读范围。
- 为知识点选择典型例子。逐步解释做了什么、为什么可以这样做、用了什么规则，最后只改变一个条件演示变化。
- 将本课目标拆成知识节点，用简短判断、解释或应用题检查理解。
- 分别记录“教师讲到哪里”“学生表现出什么理解”“是否实际运行过”，避免把听过当成学会。
- 在节点推进、学生回答、插问、阅读安排或停课时更新检查点；下次读取记录后继续。

技能的具体规则在 [SKILL.md](SKILL.md)。它是一组工作指引和模板，需要配合能读取、修改本地文件的 AI 工具。你自行准备教材；本仓库不包含教材、模型或个人学习记录。

这些规则有助于发现遗漏和恢复进度，但不能保证模型永不出错。涉及教材疑点、理解判断和实际运行结果时，仍要核对依据。

## 完整度优先，时间怎样使用

**确认要学的内容后，讲解完整是宣布完成的必要条件。** 必要定义、关键推导、典型例子、单条件变式和学习检查都要保留。教师讲完、你表现出理解、实际运行通过，仍然分别记录。

“今天有20分钟”用于帮助 AI 估算范围、安排分段和调节节奏：

1. **范围还没确认：**AI 可以建议一个有完整起点和结尾的小单元，再和你确定。
2. **范围已经确认，但预计一次讲不完：**保留全部知识节点，分多轮或多次讲，明确剩余内容下次接在哪里。
3. **接近参考时间：**AI 说明当前位置，建议在一个自然知识单元结束后暂停。不能为了赶时间删内容、截断推导，或把未讲完改记为完成。

你随时可以明确说“现在立即停”。此时 AI 应立即停止讲解，保存具体停在哪一步及剩余内容，尊重你的停止要求。

课程也要有边界。已确认的目标保持固定；超出范围的插问记录为可选后续，不自动变成更多必讲内容。改变解释方式不会自动扩大课程范围。

## 开始前准备

你需要：

1. **一个能读写本地文件的 AI 工具。** 它应能实际打开你指定的文件，并保存修改。只有聊天框、无法访问电脑文件的工具，不能直接使用本教程的本地续学流程。
2. **一份已有教材或笔记。** 先用一篇简短的 Markdown 或纯文本笔记最方便。其他格式需要你的 AI 工具能够读取；图片或扫描件读不清时应说明，不能猜内容。
3. **三个分开的文件夹。** 一个放技能，一个放教材，一个放学习产出。

不需要安装 Git、Python，也不需要开启 Goal。下面采用“在聊天中让 AI 读取技能文件”的方式，不依赖某个客户端的技能安装目录。

## 1. 下载并解压技能

1. 点击 [下载 ZIP 压缩包](https://github.com/KamisanaAtair/point-study-skill/archive/refs/heads/main.zip)。浏览器会下载一个通常名为 `point-study-skill-main.zip` 的文件。
2. 在下载位置找到这个文件。Windows 上右键选择“全部解压缩”；macOS 上双击解压；Linux 上使用文件管理器的解压功能。
3. 打开解压后的文件夹，找到 `SKILL.md`、`README.md` 和 `assets` 文件夹。**不要直接在压缩包窗口里使用它们。**
4. 将这一层文件夹放到你选好的位置，可以把文件夹名改为 `point-study-skill`。

完成后，你应当能在普通文件夹里看到 `SKILL.md`，而不只是看到一个 `.zip` 文件。

## 2. 准备教材和产出位置

下面用 Windows 示例说明。你可以选择其他位置，后面的路径必须跟着替换。

```text
C:\PointStudy\
├─ point-study-skill\    解压得到的技能文件夹，里面有 SKILL.md
├─ materials\           把你的教材、笔记放在这里
└─ outputs\             保存配置、讲义、练习和进度
```

1. 建立一个学习用文件夹，例如 `C:\PointStudy`。
2. 在里面分别建立 `materials` 和 `outputs` 文件夹，再放入解压好的 `point-study-skill` 文件夹。
3. 把教材放入 `materials`，保留它的原始内容。它们默认只供 AI 阅读。

如果不能在 `C:\` 下创建文件夹，改在自己的“文档”目录建立 `PointStudy` 即可，不需要申请管理员权限。技能、教材和产出三个文件夹应当并列，不能相同，也不要互相包含。

完成后，你应当知道：技能在哪里、教材在哪里，以及新产出将保存在哪里。

### 怎样复制完整路径

“路径”是电脑定位文件的位置文字。例如，`C:\PointStudy\point-study-skill\SKILL.md` 指向一个文件，`C:\PointStudy\materials` 指向一个文件夹。

- **Windows：**打开目标文件夹，按 `Ctrl+L` 选中地址栏，再按 `Ctrl+C` 复制。要得到文件路径，在文件夹路径末尾加上 `\文件名`。例如复制技能文件夹路径后，加上 `\SKILL.md`。
- **macOS：**在 Finder 中选中文件或文件夹，按 `Option+Command+C` 复制完整路径。
- **Linux：**在文件管理器中打开文件夹，通常可按 `Ctrl+L` 显示并复制路径；文件路径是在其后加 `/文件名`。

不同系统可以使用下面这样的路径；`your-name` 只表示你自己的用户目录，需要换成实际路径：

| 系统 | 教材目录示例 | 产出目录示例 |
|---|---|---|
| Windows | `C:\PointStudy\materials` | `C:\PointStudy\outputs` |
| macOS | `/Users/your-name/PointStudy/materials` | `/Users/your-name/PointStudy/outputs` |
| Linux | `/home/your-name/PointStudy/materials` | `/home/your-name/PointStudy/outputs` |

## 3. 复制并填写配置

配置告诉 AI 去哪里读教材、把结果写在哪里。只需填写三个项目。

1. 打开技能文件夹中的 `assets`。
2. 复制 `study-config.example.md`，粘贴到你准备的 `outputs` 文件夹。
3. 把复制后的文件重命名为 **`study-config.md`**。不要改动技能文件夹中的原模板。
4. 用纯文本编辑器打开它，例如 Windows 的“记事本”。保留三个字段名，填写你自己的路径和课程目录名。

示例内容如下。只有你确实采用上面的文件夹结构时，才直接使用这些路径：

```yaml
materials_root: 'C:\PointStudy\materials'
output_root: 'C:\PointStudy\outputs'
course_id: 'my-course'
```

| 字段 | 填什么 |
|---|---|
| `materials_root` | 教材文件夹的完整路径，不能填某个文件的路径。 |
| `output_root` | 学习产出文件夹的完整路径。不要填教材或技能文件夹。 |
| `course_id` | 当前课程的目录名。例如 `my-course`。只填一个名称，不要带 `/`、`\` 或 `..`。 |

保存修改后，这份文件就是本次运行配置，无须额外激活。如果你的真实目录恰好与示例相同，可以保留这些值。配置文件是供 AI 阅读的文字，里面的代码框不需要运行，也不需要安装 YAML 软件。

Windows 可能隐藏文件扩展名。若重命名时看到原文件名是 `study-config.example`，把它改为 `study-config` 即可，保留已有的 `.md` 扩展名。不要用记事本另存成 `study-config.md.txt`；不确定时，在文件夹的“查看”选项里开启“文件扩展名”后核对。

完成后，示例位置应当存在 `C:\PointStudy\outputs\study-config.md`，其中三个值都与你自己的情况一致。

配置模板也可在仓库中查看：[study-config.example.md](assets/study-config.example.md)。

## 4. 让 AI 开始第一课

在你的 AI 工具里打开或添加技能、教材和产出文件夹。工具如果询问文件访问权限，只允许本次使用所需的目录即可。

新建一个聊天，复制下面的提示词。**发送前把两条文件路径替换成你自己复制的真实路径。**

```text
请读取以下技能文件和学习配置，并按技能作为我的老师：

技能文件：C:\PointStudy\point-study-skill\SKILL.md
配置文件：C:\PointStudy\outputs\study-config.md

先检查你能否实际读取教材，并在配置约定的产出目录保存文件。
请先读取相关教材，不要假设我提前读过。
询问我本次范围、已有基础、希望达到的目标和参考时间预算。
已有基础不确定时可以记为“未知”；我已提供的信息不必重复问。
范围未确认时，可以建议一个完整小单元；范围确认后，以完整讲解为完成条件。
时间用于估算、分段和调节节奏，不得因预算到点删去定义、推导、例子、单条件变式或学习检查。
如果一次讲不完，保留全部节点并安排后续；接近预算时建议在自然知识单元边界暂停。
我明确要求立即停时，请停止讲解并保存精确断点。
确定本课目标后建立知识节点，再从第一个节点开始讲解。
需要我回答时，保存待答位置并等待。
```

AI 可能会接着询问学习范围。你可以这样回答，再换成自己的内容：

```text
本次范围：materials 中“分数入门.md”的分数加法部分。
已有基础：知道分子和分母，不会通分。
希望达到：能解释为什么要通分，并能完成简单计算。
参考时间预算：20 分钟；若完整范围需要更久，可以分次讲完。
```

如果你还不知道从哪篇教材开始，可以先请 AI 只查看教材目录，建议一个完整小单元并说明预计分段，再由你确定范围，不需要先读完整套材料。

## 5. 检查是否配置成功

首次开课后，核对下面几件事：

1. AI 能说明实际读到了哪份教材，并给出与本次范围对应的课程目标。
2. AI 建立了带编号的知识节点，每个节点都有“学完应能做什么”和对应的小检查。
3. 你在产出目录中实际找到了进度文件。例如：

   ```text
   C:\PointStudy\outputs\notes\my-course\学习进度.md
   ```

4. 打开进度文件，能看到当前节点、已讲与待讲内容、待答问题和下一步。没有学生回答的检查应保持待检查，不能写成已经掌握。

其他产出按用途放在下面的位置；没有相应产出时不必提前建立空文件夹：

```text
outputs\
├─ study-config.md
├─ notes\my-course\       讲义、笔记、唯一的学习进度.md
├─ code\my-course\        代码和可运行练习
└─ artifacts\my-course\   图片、运行输出等其他产出
```

`my-course` 来自你配置中的 `course_id`。学习进度模板见 [progress-template.md](assets/progress-template.md)，AI 在首次初始化时会参考它。不要用空模板覆盖已有进度。

仅在聊天中说“已保存”不代表成功。文件应当确实存在，内容也应与课堂实际相符。

## 6. 暂停后怎样继续

你可以说“先停在这里”，让 AI 保存精确断点、待补内容和下一步。

在原聊天中继续时，说“从上次断点继续”。**打开新聊天或更换 AI 工具后，需要再次提供技能和配置的路径。** 手动读取方式不会自动把技能永久加入每一个聊天。

新聊天中可复制下面的提示词，并替换路径：

```text
请读取以下文件，恢复同一门课程：

技能文件：C:\PointStudy\point-study-skill\SKILL.md
配置文件：C:\PointStudy\outputs\study-config.md

先根据配置读取已有的学习进度.md、当前整课目标、全部节点和必要教材。
告诉我停在哪个节点、还有哪些内容、下一步是什么，再从断点继续。
不要重新初始化或覆盖已有进度，不把“已读”或“已讲完”直接当成“已掌握”。
保留已确认的完整范围。时间预算只用于估算、分段和调节节奏，不要为了赶时间删减未讲内容。
如果保存记录与最近对话不一致，请先核对，不要猜测。
```

完成后，AI 应当接上原来的待答或待讲位置，同时保留本课尚未完成的节点。意外关闭程序时，最近一段可能来不及保存；应先核对最后成功保存的记录，再继续。

同一门课尽量只让一个聊天负责写进度。如果同时让多个 AI 修改同一份文件，容易互相覆盖。更换负责的工具时，先暂停原来的课堂并保存记录。

## 常见问题

| 现象 | 你可以怎么做 |
|---|---|
| AI 说找不到 `SKILL.md` | 检查压缩包是否已解压；重新从文件管理器复制真实文件路径，确认末尾有 `SKILL.md`。 |
| AI 看不到教材或不能保存 | 在工具中添加相应文件夹并检查访问权限。若工具本身不支持本地文件读写，需要换用支持该能力的工具。 |
| 路径里还写着 `your-name` 或示例位置 | 将它换成真实路径。不要把示例文字当成自己的配置。 |
| 找不到配置文件 | 检查是否放进了产出目录，是否误命名为 `study-config.md.txt`，以及提示词中的路径是否一致。 |
| AI 只能给出保存失败提示 | 保留它提供的恢复摘要，检查产出位置是否可写；恢复写入后先核对摘要再续讲。不要把失败当作已保存。 |
| 新聊天又从第一课开头开始 | 重新提供技能和配置路径，明确要求读取已有的 `学习进度.md`，并确认 `course_id` 没有改变。 |
| 已经读过教材，却被记为掌握 | 请 AI 分开记录阅读范围、教师讲解和学生回答；只有实际表现才能支持理解判断。 |
| 进度只剩当前问题，其他目标消失 | 请 AI 对照本课全部节点与课程范围核查，把遗漏项恢复为待讲或待补，再继续。 |
| 时间快到了，但内容还没讲完 | 请 AI 保留全部目标，说明当前单元还差什么，建议在自然知识单元边界暂停并把余下内容记为待续。不要删去推导或学习检查来赶时间。你需要立即停时，直接说“现在立即停”。 |

## 更新技能

需要更新时，重新下载并解压到一个新位置。核对新版本后，再替换旧的技能文件夹。

教材和 `outputs` 独立保留。不要用下载包里的空模板覆盖自己的 `study-config.md` 或 `学习进度.md`。如果技能位置变了，后续启动提示词里的路径也要修改。
